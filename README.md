# Smart CCTV Ramadhan ESP32-CAM
Project ini adalah sistem keamanan berbasis IoT menggunakan ESP32-CAM, sensor PIR, dan Buzzer.
​### Fitur Utama:
* Monitoring: Live stream via IP Address.
* Security: Deteksi gerakan otomatis via PIR sensor.
* Alarm: Buzzer untuk alarm sahur dan peringatan maling.
​### Konfigurasi Pin:
* GPIO 4: Flash LED
* GPIO 12: Buzzer
* GPIO 13: Sensor PIR
